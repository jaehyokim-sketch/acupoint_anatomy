### 第二版前言

《中国针灸穴位通鉴》（王德深主编）、《中国针灸经络通鉴》（邓良月主编）、《中国针灸刺灸法通鉴》（黄龙祥主编）、《中国针灸证治通鉴》（邓良月、黄龙祥主编）合称《中国针灸四大通鉴》。20世纪90年代由青岛优秀图书出版基金资助，青岛出版社出版。第一版为繁体字本，按预订数出版，是中国针灸科学技术专著力作之一，深受读者欢迎和社会好评。2000年12月，获北京市政府“科学技术专著进步奖”。

《中国针灸穴位通鉴》的编撰过程和体例参见第一版前言和编写说明。

这次再版修订，改出简体字本。修订工作始于2002年2月，历经二年半有余。除对书中错字、疏漏、穴位图注错误等作了改正以外，还着重对以下部分作了较大的修订和补充。

①每穴最后的“简要结语”部分中的“主治病症”项下，分别按各文献先后时序加注了序号：1、2、3、……，并将唐代以前的文献名后移。

②将第四编“古代针灸穴位图选”改为“针灸穴位图选”。因为在第五篇“清代针灸穴位图选”后增加了一篇，即第六篇“现代的国际标准针灸穴位图”计136幅，以便能起到通览古今，古今并重，在继承的基础上有所发展的桥梁作用，为针灸学者考察了解古今主要针灸穴位图之不同特征及其发展创新之趋势提供一些可比较的图式。

③晋代《针灸甲乙经》对针灸穴名作过一次标准化整理工作，首出常用穴名，即标准化穴名或称正名，对一些曾用名或称别名的附录于正名之后，以一名××、一名××，或名××形式著录之。如百会一名三阳五会，中脘一名太仓，关元一名次门，天枢一名长溪、一名谷门，等等。唐宋以来的针灸文献中也偶见一些新穴名，如为避讳唐祖李渊名讳将太渊改为大泉，将渊腋改为泉腋，等等。有些别名系后人传抄之误，以致以讹传讹。现将本书中出现的别名辑出，经过整理编排，成为“针灸穴名别名索引”填补了以往文献方面的空白，以便于检索对照。

〔p.6〕

④1989年10月30日至11月3日，世界卫生组织（WHO）在日内瓦总部召开了全球性的国际标准针灸穴名科学组会议，审议采纳了由穴名汉字、汉语拼音穴名和英文字母数字编号三要素组成的“国际标准针灸穴名”，从而为将起源于中国并不断发展的中国针灸医学在国际间的推广和发展进一步拓宽了道路，其意义重大，影响深远。1991年，世界卫生组织出版了这次会议报告：《国际标准针灸穴名》，确立了以“汉语拼音穴名”为基础的国际标准针灸穴名的地位。1992年人民卫生出版社出版了该书中译本，作为附篇之一附于书后，以便于读者和中医针灸编译工作者参阅和推广应用。

### 第一版前言

针灸医学是祖国医学宝贵遗产中的重要组成部分；其中的穴位部分又是针灸医学中的极其重要部分，在一般针灸书中通常约占全书的三分之一乃至二分之一。为了发扬中医针灸特色，继承和发掘针灸遗产中穴位部分的宝贵内容，使其更好地为发展现代针灸的科研、教学和医疗服务，特将我国历代具有代表性的针灸医籍（包括综合性医籍中的针灸专卷）中的穴位项下内容，分门别类，按历史年代编排，以示相互承袭和发展关系，以期为国内外针灸学界提供执一书而通览历代诸针灸书中穴位内容的目的。故名为《中国针灸穴位通鉴》。

本书的编撰研究工作，断断续续历时30余载。开始于1958年，是中医研究院针灸研究所针灸文献理论研究室的科研项目之一。至1963年已收集了80多部古代针灸医籍中有关穴位内容的卡片两万余张，写过样稿，征求过意见。1964年因工作人员的调动和随之而来的文化大革命等，编撰工作停顿了下来。1977年，此项课题的全部卡片资料又物归原主，从而又继续进行编撰工作。

1984年以来，本书编撰研究工作列为中国中医研究院针灸研究所的科研项目。经过各方协作和科室的科研人员共同努力，先后三易其稿，终于完成了此书的编撰工作。

参加过编写此书的初期工作人员还有：马继兴、赵尔康、陆卓珊、霍瑞兴、梁富义、洪英、周愉真等医师。青岛出版社对此书的出版给予了极大的支持。在此一并致以衷心的谢意。

由于经验不足，水平所限，书中难免有疏漏错误之处，欢迎同道和读者批评指正。

王德深

1991年9月于北京中国中医研究院针灸所

### 第二版编写说明

一、全书分为五编：第一编取穴尺寸法；第二编十四经穴；第三编经外穴；第四编针灸穴位图选；第五编附编，计有国际标准针灸穴名、耳穴、穴名索引和引用书目等。

二、本书穴名是参照世界卫生组织国际标准针灸穴名科学组会议（1989年）审议采纳的《国际标准针灸穴名》和《中华人民共和国国家标准·经穴部位》（1990年）中穴名著录的。首为汉文穴名，次为拼音穴名，再次为编号。

三、每一个穴位分九项著录：出处、别名、穴名释义、部位、归经与穴性、主治病症、针法灸法与感传、局部解剖和简要结语。

(一)出处　提示该穴名和其内容首出何书并注出卷页。

(二)别名　有一些穴位有一个或数个别名。凡有别名的均辑录于此项下，求同存异，各按医籍时序排列。两个以上别名，则用1、2、3……标出。无别名者则注“无”。

(三)穴各释义　每一个穴名都有一定的含义。凡解释穴名意义的内容均辑录于此项下，求同存异。对不相同的内容则分别辑录，用1、2、3……标出。

(四)部位　凡有关该穴的部位、取穴法、体表定位等方面内容，均辑录于此项下，对不同部分的记述则求同存异，各按医籍时序排列，不相同者用1、2、3……区分之。

(五)归经与穴性　十四经穴分别属于各自经脉。凡“××脉气所发”，或“系某经穴”等内容均辑录于此项下。

穴性是指该穴位的属性而言。如：“根结、标本、井、荥、俞、原、经、合、络、郄、背俞、募穴、交会穴”等性质。凡此类内容均辑录于此项下，求同存异，各按医籍时序排列。

(六)主治病症　凡穴位项下之主治病症（含辨证施治之具体刺灸法）以及穴位配伍应用（数穴主治同一病症）方面内容，皆辑录于此项下，求同存异，各按医籍时序排列。不相同者则分别辑录，用1、2、3……区分之。

(七)针法、灸法与感传（得气）　凡有关该穴位的针法、灸法、感传（得气）以及禁针、禁灸等内容，皆辑录于此项下，求同存异，各按医籍时序排列。

〔p.9〕

(八)局部解剖　古代针灸医籍穴位项下无“局部解剖”方面内容，20世纪30年代，国内出版的针灸书中的穴位项下，始见有“局部解剖”内容，其后出版的一些针灸书也相继出现了这方面内容。凡穴位项下的局部解剖方面的内容，均辑录于此项下，求同存异，各按医籍时序排列。

(九)简要结语　是对以上各部分内容做一简要概括。起到突出重点，画龙点睛的作用。

四、凡引文均用引号“××××”标出。

五、引文中所夹的圆括弧“(××××)”内容是其原有注释。古医籍多用双行小字排印。今为便于排版改为单行，加以圆括弧，以便与正文有所区分。

六、凡引文皆在其后注出书名，用圆括弧括之。首出的引用书名附有卷数和页码，其间用冒号“：”隔开。冒号前者为卷数，冒号后者为页数。

1901年以后编辑出版的书籍，一般都略去了卷，只注出页。

七、对医籍中的“古今字”、“通假字”、“异体字”、“脱漏字”、“衍文”、“错别字”等作了简要的校注。对一些有明显歧义的论点做了简要的按语或评述。

八、世界卫生组织1989年审议采纳了国际标准经外穴名（48个）并给经外穴下的定义是：“经外穴是泛指361个十四经穴以外的全部穴名而言。”

本书除收录了全部标准化的经外穴以外，还收录了见于古代文献中其他经外穴，即未标准化穴名。计182个。

九、书后附有引用文献与其版本，以便于参阅。

王德深

2004年9月于北京中国中医研究院针灸所

### 【第二篇】 折量寸法

取穴的准确与否可直接影响着疗效。《标幽赋》中说：“取五穴用一穴而必端，取三经用一经而可正。”说明正确取穴的重要性。

古书所载测定穴位所用的尺度，并非使用一定的度量工具，而是根据身体的不同部位，将其某两点之间的长度或宽度折作若干等份寸，作为量度穴位的标准。一般可分为一夫法、折量寸法、中指同身寸法三种。

折量寸法：又名等分法，古称骨度法。即根据身体的胸、腹等不同部位或区，将其设定的两点之间的距离折为若干等分段，以其中的一段即为该部位的一折量寸，简称一寸。审定头部、胸部、腹部、上肢和下肢等穴位时，多用本法。如两乳头之间折作八寸，用以审定胸腹部穴位横距离间的尺寸；胸骨剑突尖至脐折作八寸，用以审定腹上部穴位的纵距离间的标准；脐（神阙）至耻骨联合上缘（曲骨）折作五寸，用以审定下腹部穴位的纵距离的标准。前臂肘掌侧横纹至腕掌侧横纹折作为一尺二寸，用以审定前臂掌侧手三阴经穴位的纵距离标准等。

5. 审定腹部穴位的标准（如表2-2）：

腹部的穴位，有任脉、肾经、胃经、脾经、胆经、以及肝经等穴。

（1）腹部穴位直行寸（纵距离）：任脉穴：本经穴在腹部穴的纵距离间标准，分脐上段和脐下段。脐上段是由胸骨剑突至神阙穴（脐）间之距离折为八等份寸，每寸定一穴；脐下段由神阙穴（脐）至曲骨穴（耻骨联合上缘上方之凹陷处）之间的距离折作五等份寸，每寸定一穴。但于第二寸的中点（即脐下一寸五分处）定气海穴。

肾经穴与胃经穴：这二经腹部段穴位的纵距离间的标准，皆根据任脉穴之纵距离间的标准。

（2）胸腹穴位横寸（横距离）：两乳头之间的距离折为八等分寸。

**表2-2→②　审定腹部穴位的尺寸法**

|  |  | 部位起止 | 骨度（寸） |
|---|---|---|---|
| 横行寸（横距离） |  | 肾经→任脉 | 0.5 |
|  |  | 胃经→任脉 | 2 |
|  |  | 脾经→任脉 | 4 |
| 直行寸 | 脐上 | 剑突尖→脐 | 8 |
|  | 脐下 | 脐→曲骨（耻骨联合上缘） | 5 |

（《针灸学简编》：45）

【按】综合以上文献所述，可见腹上部直寸是由臆前蔽骨尖（胸骨剑突尖）至脐中（神阙穴）折为八寸，下腹部由脐至曲骨折作五寸，用以审定腹部任脉穴及其两侧的肾经穴、胃经穴和脾经穴。

中脘穴恰居其腹前正中线的中间，中脘上一寸为上脘，上脘上一寸五分为巨阙，巨阙上一寸五分为鸠尾。鸠尾上五分为臆前蔽骨尖（即胸骨剑突尖）。

中脘以下至脐作四寸，其间每寸一穴。

下腹部由脐至曲骨折作五寸。其间每寸一穴。但在脐下一寸五分处多一气海穴。

《备急千金要方》之腹上穴直寸法与《针灸甲乙经》基本相同。不同处有：脘，作“管”；“上管在巨阙下一寸，去蔽骨三寸。”疑“一寸”之下脱“五分”二字。“水分在下管下一寸，脐上一寸。”

横寸　以两乳头之间距离折作八寸。以腹中线（即任脉）为纵坐标，肾经的幽门至横骨的十一穴去中行任脉半寸。胃经的不容至气冲十二穴旁开中行任脉二寸。肝经的期门与脾经的腹哀至冲门的七穴在中行任脉穴外侧四寸。但《针灸甲乙经》、《备急千金要方》的这段文字似有矛盾之处。“上直两乳”应去中行四寸。如果“夹不容两旁各一寸五分”则应去中行三寸五分，与直乳不符。后世文献多从上直两乳，去中行四寸之法。

### 【第三篇】 指寸法

#### 一. 一夫法

1. “以病人手横掩下并四指，名曰一夫。”（《肘后备急方》3：80）

2. “凡孔穴在身，皆是脏腑荣卫血脉流通，表里往来，各有所主。临时救难，必在审详。人有老少，体有长短，肤有肥瘦，皆须精思商量，准而取之，无得一概，致有差失。其尺寸之法，依古者八寸为尺，仍取病者男左女右手中指上第一节为一寸。亦有长短不定者，即取手大拇指第一节横度为一寸。以意消息，巧拙在人。其言一夫者，以四指为一夫，又以肌肉纹理节解缝会宛宛之中，乃以手按之，病者快然。如此仔细安详用心者，乃能得之耳。”（《备急千金要方》29：518）

3. “凡量一夫之法，覆手亦舒四指，对度四指上下节横过为一夫。夫有两种：有三指夫者；若灸脚弱，以四指为一夫也。（见《脚气》）。”（《针灸资生经·审方书》2：5）

4. “一夫法：即横指寸法。将食、中、环、小四指相并，其四横指之宽度，称为一夫，相当为三寸。多用于审定小腿穴、下腹部穴直寸的标准。如犊鼻下一夫（四横指）取足三里。”（《针灸学简编》：38）

#### 二. 同身寸

1. “《岐伯明堂经》云：‘以八寸为一尺，以八分为一寸，人缘有长短，肥瘦不同，取穴不准。’秦时《扁鹊明堂》云：‘取男左女右手中指第一节为一寸。为缘人有身长手短，有身短手长，取穴不准。”唐时孙思邈《明堂经》云：“取患人男左女右手大拇指节横纹为一寸，以意消详，巧拙在人，亦有差互。今取男左女右手中指第二节，内度两横纹相去为一寸。自依此寸法与众人著灸疗病以来，其病多得获愈。此法有准，今以为定。”（《太平圣惠方·明堂序》100：3204）

2. “《下经》曰：“岐伯以八分为一寸，缘人有长短肥瘦不同，取穴不准。扁鹊以手中指第一节为寸。缘人有身长手短，身短手长，取穴亦不准。孙真人取大拇指节横纹为一寸，亦有差互。今取男左女右手中指第二节，内度[1]两横纹为一寸。（若屈指即旁取指，则中节上下两纹角陷相去远近为一寸，谓同身寸）自依此寸法与人著灸疗病多愈。今以为准。《铜人》亦曰：取中指内纹为一寸。《素问》云：同身寸是也。又多用绳度量，绳多出缩不准。今以薄竹片点量分寸，疗病准的。亦有用蜡纸条量者。但薄篾易折，蜡纸亦粘手，而取[2]稻秆心量却易，为胜于用绳之信缩也。”（《针灸资生经·论同身寸》2：4）

3. “同身寸者，谓同于人身尺寸也。人之长短肥瘦各自不同，而穴之横直尺寸亦不能一。如今以中指同身寸法一概混用。则人瘦而指长，人肥而指短，岂不谬误？故必因其形而取之，方得其当。如《标幽赋》曰：‘取五穴用一穴而必端，取三经用一经而可正。’盖谓并邻经而正一经，取邻穴而正一穴。譬之切字之法，上用一音，下用一韵，而夹其声于中。则其经穴之情，自无所遁矣。故头必因于头，腹必因于腹，背必因于背，手足必因于手足，总其长短大小而折中之。庶得谓之同身寸法。法附前各条之下，而后之所谓中指同身寸法者，虽不可混用，而亦有当用之处，并列于后。（《类经图翼·同身寸说》3：85）

> [1] 原作“内庭”参校《太平圣惠方》，为“内度”，据改。
> [2] 原作“取取”，费解，径改。

〔p.53 (인쇄 18)〕

“以男左女右手大指中指圆曲交接如环，取中指中节横纹两头尽处，此为一寸。凡手足尺寸及背部横寸，无折法之处，乃用此法，其他不可混用。”（《类经图翼·中指同身寸法》3：86）

4. “中指同身寸法：是指患者中指第一指间关节与第二指间关节横纹头之间的一段距离（中指与拇指屈曲成环形）当作一寸，这叫做中指同身寸。本法多用于度量穴位的纵横距离间的标准。”（《针灸学简编》：38）
