# 영추 십이경맥 4대 병증 고증 & 동의보감 상병명 탐색기 (연구용)

- **분석 순서**: ①『영추』 원전(곽애춘 정본) → ② 황룡상 고증([황룡상] 연구 모드 코퍼스 DB 확인) → ③『중의백병명원고』 병명 훈고 → ④『동의보감』 상응 병증 추출 → ⑤『침구임상변증론치』 변증 → ⑥ HIRA 현행 KCD-8/9 연결(의과 + 한의 U코드) → ⑦ 임상 코딩 가이드
- **원전 및 자료**:
  1. 곽애춘 편저, 『황제내경영추 교주어역』 제10편 경맥 · 제13편 경근
  2. 허준, 『동의보감』 鍼灸篇 「○經流注」(p.773~788) · 「十五絡所生病」(p.791) · 外形篇 「筋·十二經皆有筋」(p.301~302)
  3. 『중의백병명원고(中医百病名源考)』, 이세진 『침구임상변증론치』
  4. 황룡상, 『중국침구학술사대강』 · 『중국침구경락통감』 · 『针灸腧穴通考』 · 『经脉理论还原与重构大纲』 · 『中国古典针灸学大纲』 및 학술논문
  5. 건강보험심사평가원 질병정보서비스 OpenAPI(상병마스터·성연령별·종별 진료통계, 2026-11-08 조회)
  6. 『임상한의사를 위한 KCD지침서 개정증보판』(KCD-7) — KCD-8/9 전환 참고용
- **주요 기능**: 12경맥 4대 병증 통합 검색, 병증 탭·경맥군 필터, 카드/비교표/황룡상 이론/정제·검증 로그 뷰, 7단계 상세 분석 모달, 십오락맥(임·독·대포 포함) 상세
