## 0. 요약 (Executive Summary)

1. **고전 천부·협백은 위팔 안쪽 위팔동맥 박동점이다.** 《针灸甲乙经》·《黄帝内经明堂》은 천부를 "腋下三寸, 臂臑內廉動脈中", 협백을 "在天府下, 去肘五寸動脈中"으로 기술한다. 송석모(2022)와 황룡상(《针灸腧穴通考》)은 이 "動脈"을 모두 위팔두갈래근 안쪽고랑을 지나는 **위팔동맥(brachial artery)**으로 본다.
2. **현대 WHO 정위는 위팔두갈래근 가쪽 모서리로, 고전 정위와 다른 장소다.** 두 지점의 공간 편차는 해부학적 추정으로 약 25~35mm(모델값 ≈ 29mm)이며, Δ > 15mm 기준을 넘으므로 **Target 1(고전 동맥점, cLU3/cLU4)과 Target 2(WHO점, pLU3/pLU4)로 나누어 분석**해야 한다. 기존 천부 보고서의 "Δ ≈ 3mm, 단일 타깃" 판정은 철회한다.
3. **두 연구자는 진단에서는 같지만 처방은 다르다.**
   - 송석모: WHO 위치는 오류이므로 **천부·협백을 위팔동맥 위로 되돌려야 한다.**
   - 황룡상: 《灵枢·经脉》 단계에서 이미 수태음 노선이 위팔 노쪽으로 옮겨갔고, 현대 정위는 그 변화를 늦게 반영한 것이다. 문제는 위치가 아니라 **위치는 바뀌었는데 주치·층차해부·자법은 고전 동맥점의 것을 그대로 물려받은 "명실분리(名實分離)"**에 있다. "今之天府已非古之天府"
4. **이 보고서의 판정 (이원 타깃 병존 모델)**:
   - 고전 주치(鼻衄·喘咳 / 心痛·煩滿)는 **Target 1(cLU3·cLU4)**에 귀속한다.
   - Target 2(pLU3·pLU4)는 **국소 위팔 통증**이 주 적응증이며, 고전 주치를 그대로 옮겨 붙이는 것을 경계한다.
5. **생의학 근거 수준**: 마스터 DB에 LU3·LU4 관련 **실측 생리·임상 논문은 0편**이다(LU3 13편, LU4 1편 모두 문헌사 연구). 따라서 Layer A가 비어 있어 **67% Refinement를 통과하지 못하며**, 아래의 반사 기전은 Layer B(공인 해부·생리 모델)에 근거한 **가설**이다.
6. **ARI(재산출)**:

## 4. 3D 공간 좌표 및 Layer 1~5 층차 구조 (Rank 5)

### 4.1 좌표계와 이원 분기

좌표 원점은 해당 높이에서 위팔 앞면 정중선이다.
- X: 안쪽 −, 가쪽 +
- Y: 앞겨드랑주름에서 먼쪽 방향 (mm)
- Z: 피부면에서의 깊이

| 지표 | Target 1: 고전 동맥점 (cLU3 / cLU4) | Target 2: WHO 정위 (pLU3 / pLU4) |
| :--- | :--- | :--- |
| 체표 정위 | 위팔 안쪽면, 위팔두갈래근 **안쪽 모서리**의 안쪽고랑, 위팔동맥 박동 위. cLU3 = 앞겨드랑주름 아래 3촌, cLU4 = 그 아래 1촌(팔꿈치 위 5촌) | 위팔 앞가쪽면, 위팔두갈래근 **가쪽 모서리**. pLU3 = 앞겨드랑주름 아래 3촌, pLU4 = 4촌 |
| 취혈 지표 | "動脈應手". 손바닥을 앞으로 둔 자세에서 안쪽고랑의 맥박을 촉진 | 위팔두갈래근 긴갈래의 가쪽 모서리, 노쪽피부정맥 주행선 |
| 모델 좌표 (기존 비교보고서 값 유지) | cLU3 (X −14.5, Y 69, Z 18.2) / cLU4 (X −13.2, Y 92, Z 17.5) | pLU3 (X +13.8, Y 69, Z 12.0) / pLU4 (X +14.5, Y 92, Z 11.5) |
| 공간 편차 Δ | **cLU3–pLU3: √(28.3² + 6.2²) ≈ 29.0mm**, **cLU4–pLU4: √(27.7² + 6.0²) ≈ 28.3mm** | 기준점 |
| 분기 판정 | **Δ > 15mm → 이원 분기 확정** | — |

> 좌표값은 실측이 아니라 성인 위팔두갈래근 폭(약 25~40mm)에 근거한 **모델 추정값**이다. Y는 1촌 ≈ 23mm(앞겨드랑주름~팔오금 9촌 기준)로 환산했다. 기존 비교보고서의 Y값(220/195mm)은 기준점이 명시되지 않아 앞겨드랑주름 기준으로 바꾸었다.

### 4.2 Layer 1~5 층차 (프레임워크 v2.6 심도 구간)

| Layer (심도) | Target 1: cLU3 / cLU4 (안쪽 동맥점) | Target 2: pLU3 / pLU4 (가쪽 모서리) |
| :--- | :--- | :--- |
| **L1** 피부 (0~3mm) | 안쪽위팔피부신경(T1), 갈비사이위팔신경(T2) 영역 | 위가쪽위팔피부신경(겨드랑신경, C5; pLU3 높이), 아래가쪽위팔피부신경(노신경, C5-6; pLU4 높이) |
| **L2** 피하·얕은근막 (3~8mm) | 피하지방. 자쪽피부정맥은 위팔 중간쯤에서 깊은근막을 뚫음(cLU4 높이 부근) | **노쪽피부정맥(cephalic v.)**, 가쪽 위팔두갈래근고랑 |
| **L3** 깊은근막·근육 가장자리 (8~16mm) | 깊은근막 바로 아래 **신경혈관다발**: 위팔동맥·동반정맥, **정중신경**(위팔 위쪽에서는 동맥 가쪽, 중간에서 앞으로 교차), 자신경(위쪽에서 동맥 안쪽), 안쪽아래팔피부신경. 체격이 마른 사람은 L2 하단부터 맥박이 촉지됨 | 위팔두갈래근 긴갈래 가쪽 근복·운동점 |
| **L4** 심층 (16~22mm) | 부리위팔근(cLU3), 위팔근 안쪽(cLU4), 안쪽 근육사이막 | 위팔근 / **근피신경**(위팔두갈래근과 위팔근 사이) |
| **L5** 바닥 (>22mm) | 위팔뼈 안쪽면 | 위팔뼈 앞가쪽면 |

> 깊이 구간은 프레임워크의 표준 구간이다. 실제 깊이는 피하지방 두께에 따라 크게 달라진다(Layer B, 일반 해부학 지식).

**해석**
- 고전의 4푼(≈9.2mm)은 **안쪽 동맥점에서 신경혈관다발 깊이와 겹친다.** 고전의 얕은 자침 규정과 천부 금구(禁灸)는 "大脈 위의 혈"이라는 특성에서 나온 것이다. 《通考》는 "古代文獻所言'禁灸'是針對位於大脈中的'天府'而言，現代的定位已不在脈中"이라고 적는다.
- 현대의 0.5~1촌 직자는 가쪽 근육점(pLU)을 전제로 한 깊이다. **이 깊이를 안쪽 동맥점(cLU)에 그대로 적용하면 위팔동맥·정중신경 손상 위험이 있다.**
- **cLU 자침 안전 수칙 (제안)**:
  1. 맥박을 촉지한 뒤 손가락으로 동맥을 비켜 고정한다.
  2. 동맥 옆으로 얕게(≤ 3~4푼, 약 7~9mm) 자입한다.
  3. 전격감(정중신경 자극)이 나타나면 즉시 침을 뺀다.
  4. 직접 뜸은 하지 않는다.
- 기존 비교보고서의 "동맥벽을 스치듯이 사침"이라는 권고는 **안전상 철회한다.**
