## 1. 개요 및 구축 배경

본 프로젝트는 원광대학교 한의과대학 경혈학교실의 14경맥 361종 표준 경혈 데이터를 현대 임상 및 학술 표준에 맞추어 통합하고, 학생·연구자·임상의가 웹 브라우저에서 직관적으로 탐색할 수 있는 **「경혈학 핸드북 포털(Acupoint Handbook Portal)」**을 구축·배포하는 것을 목적으로 수행되었습니다.

로컬 편집 PC와 Google Drive 간의 안전한 Git 격리 분리 원칙을 준수하면서, 분산되어 있던 5대 핵심 데이터셋(핸드북 원고, 해부구조 데이터셋, 7대 문헌군 자침깊이, 황룡상 교수 고증 주치증 및 KCD 질병코드, KJH 경혈명/이명 대조 데이터)을 단일 진실원천(SSOT, Master JSON)으로 통합 정제하였습니다.

## 2. 작업 경과 및 주요 마일스톤

### 마일스톤 1: 14경맥 361경혈 핸드북 및 해부구조 데이터셋 통합
- **기반 자료**:
  - `G:\내 드라이브\강의\경혈학 교재 편찬\핸드북(한 영)\한글판` (361개 혈위 부위, 취혈법, 자구법, 주의사항)
  - `김재효 수업_경혈_해부구조_데이터셋.xlsx` (근육, 신경, 혈관 한/영 병기)
  - `경혈학공통교재 경혈_해부구조_데이터셋_refine.xlsx` (공통교재 표준 해부구조)

  - 배포 대상을 `acupoint_anatomy` 단일 저장소로 확정 (`classics` 저장소에서는 완전 이관 및 제거).

### 마일스톤 2: 주치증 정본화 및 표준 KCD 질병코드 듀얼 매핑
- **기반 자료**:
  - `경혈별 주치증 정리_V2.xlsx`

  - 《임상한의사를 위한 KCD지침서 개정증보판》
- **작업 내용**:

  - 마스터 엑셀(`경혈별 주치증 정리_V2.xlsx`) 갱신 및 카테고리별 주치증-KCD 배지 시각화 구현.

### 마일스톤 3: 7대 문헌군 자침깊이 및 자침법(침구수혈통고 등) 연계

- **작업 내용**:

  - 직자, 사자, 횡자(연피자) 등 자침법별 실시간 필터 기능 탑재.

### 마일스톤 4: KJH 경혈명 비교정리 및 「본명-이명 혼동주의 (Case A)」 경보 탑재
- **기반 자료**:
  - `G:\내 드라이브\도서 번역\acupoint_anatomy\data\경혈명_비교_정리_KJH.xlsx`
- **작업 내용**:
  - **경혈 종합 목록(361혈)**: 표준 한자 외 강의 슬라이드 표기 한자(`slide_hanja`) 및 한자 이명 목록 매핑.
  - **본명-이명 일치 목록(Case A)**: 타 경혈의 정명(본명)과 철자가 일치하는 34개 혈위(총 35개 페어)를 추출하여 포털 카드 상단에 붉은색 경보 박스(⚠️ Alert)로 표시.
  - 혼동 대상 경혈 클릭 시 해당 경혈로 즉시 화면 점프 이동 기능(`jumpToPoint`) 및 **[⚠️ 본명-이명 혼동주의]** 전용 필터 신설.

## 4. 로컬 PC 워크스페이스 동기화 및 유지관리 지침

Google Drive 클라우드 파일 시스템과 로컬 PC 작업 공간 사이의 충돌을 방지하고 Git 버전 관리를 무결하게 유지하기 위한 필수 운영 규칙입니다.

```
[로컬 PC 편집 환경]
C:\workspace\acupoint_anatomy  <--- Git 저장소 (origin/main) 관리
  ├── data/master_361_acupoints_dataset.json (SSOT 마스터 데이터셋)
  ├── tools/acupoint-handbook.html           (배포용 메인 포털 웹앱)
  ├── deploy_to_gdrive.py                    (Drive 배포 동기화 스크립트)
  └── ...
         │
         │  (1) Git Commit & Push (GitHub Pages 배포)
         ▼
[GitHub 원격 저장소 & Pages]
https://github.com/jaehyokim-sketch/acupoint_anatomy.git
         │
         │  (2) deploy_to_gdrive.py 실행 (클라우드 미러링)
         ▼
[Google Drive 환경]
G:\내 드라이브\도서 번역\acupoint_anatomy\  <--- Git 없음 (.git 절대 생성 금지)
G:\내 드라이브\강의\경혈학 교재 편찬\경혈학_핸드북_포털.html
```

### [원칙 1] Git 저장소 격리 (Git Separation)
1. **`.git` 디렉터리는 오직 로컬 PC `C:\workspace\acupoint_anatomy`에만 존재**해야 합니다.
2. `G:\내 드라이브` 내부에는 어떠한 경우에도 `git init`을 실행하거나 `.git` 폴더를 복사하지 않습니다. Google Drive 동기화 엔진과 Git 내부 데이터베이스가 충돌하여 파일 락 및 데이터 유실이 발생할 수 있습니다.

### [원칙 2] 로컬 작업 후 표준 배포 절차 (Standard Deployment Workflow)

로컬 PC에서 데이터셋이나 포털 UI를 수정한 후 다음 3단계를 순서환하여 실행합니다.

#### 1단계: Git 저장소 커밋 및 GitHub 원격 푸시
```powershell
cd C:\workspace\acupoint_anatomy
git status
git add data/master_361_acupoints_dataset.json tools/acupoint-handbook.html
git commit -m "feat: [수정 내역 기술]"
git push origin main
```
*푸시 완료 후 약 1~2분 뒤 GitHub Pages 라이브 웹 페이지에 자동 반영됩니다.*

#### 2단계: Google Drive 미러링 동기화 실행
```powershell
python C:\workspace\acupoint_anatomy\deploy_to_gdrive.py
```
*이 스크립트는 로컬의 정본 파일들을 검사하여 `G:\내 드라이브\도서 번역\acupoint_anatomy`로 안전하게 복사·동기화하며 `.git` 폴더는 자동으로 배제합니다.*

#### 3단계: 강의 편찬 폴더 바로가기 파일 갱신 확인
`G:\내 드라이브\강의\경혈학 교재 편찬\경혈학_핸드북_포털.html` 파일이 최신 버전으로 갱신되었는지 확인합니다.

## 5. 생성 및 동기화 스크립트 도구 안내

향후 엑셀 데이터가 추가되거나 주치증/자침깊이 데이터가 수정되었을 때 재빌드할 수 있는 스크립트 위치입니다.

1. **마스터 데이터 생성 및 병합 스크립트**:
   - `data/master_361_acupoints_dataset.json`이 모든 정보가 통합된 SSOT(Single Source of Truth)입니다.
2. **포털 HTML 생성기**:
   - 로컬 scratch 또는 도구 경로의 `generate_handbook_portal_v3.py`를 실행하여 JSON 데이터를 기반으로 포털 HTML을 즉시 재빌드할 수 있습니다:
     ```powershell
     python C:\workspace\acupoint_anatomy\scripts\generate_handbook_portal.py
     ```
3. **Google Drive 배치 동기화**:
   - 로컬 작업 후 `python C:\workspace\acupoint_anatomy\deploy_to_gdrive.py` 또는 `deploy_to_gdrive.bat` 더블 클릭.
